1. ThreatRAG Asol-e Ki? Keno Eti Shadharon Chatbot Noy?

Apnar mone shobcheye boro proshno hote pare: "Ami ki baniyechi? Eta ki shudhu ekta ChatGPT ba bot?"

Shohoj Kothay: ThreatRAG kono shadharon chatbot noy! Eta holo ekta Autonomous Multi-Agent Cybersecurity Co-Pilot। Ekta real Security Operations Center (SOC)-e protidin hazar hazar suspicious network alert ashe। Shadharon ChatGPT ba LLM-ke jodi security query kora hoy, shey fake CVE number, vul firewall command, ba hallucinated logic banaye dey—jar karone server crash korte pare।

ThreatRAG ei shomossha solve kore! Ekhane 4-ta Specialist Agent mile ekta disciplined team-er moto kaj kore, official MITRE ATT&CK ebong CISA KEV data theke proman (evidence) khuje ber kore, ebong human analyst-er sign-off chhara kono action dispatch kore na।

2. Apnar 4-ta Agent Asol-e Ki Kaj Korche? (Real-Life Analogy)

System-e jokhon kono network telemetry ba analyst query ashe, tokhon shob kaj ekta single model kore na। 4-jon agent nijeder moddhe responsibility divide kore ney:

Agent Name Real-Life Role Behind the Scenes Ki Kaj Kore?
1. Coordinator / Planner Agent
coordinator.py		 The Project Manager User er query pore bujhe je ki dhoroner kaj dorkar। Ekta structured workflow plan banay (e.g. Threat ID lagbe, naki Incident Search lagbe)। Baki specialist agent-der execution order manage kore ebong verification fail korle Feedback Loop chalay (max 2 retries)।
2. Cybersecurity Retrieval Specialist
retrieval_agent.py		 The Research Librarian Apnar 1,074-ta preprocessed security chunk (MITRE ATT&CK, CISA KEV, historical incidents) theke Tri-Modal Hybrid Search kore। SentenceTransformer (dense vector) + BM25Okapi (sparse keyword) + Network Port matcher run kore top-5 evidence khuje aney।
3. Security Reasoning Specialist
reasoning_agent.py		 The Senior SOC Analyst & ML Expert Trained LightGBM Classifier chalay। Anomaly-r raw score-ke Platt Scaling diye calibrate kore exact probability (e.g. 99.98% confidence) ber kore। Tarpor behavior-ke MITRE technique (e.g. T1498.001)-e map kore ebong empirical facts theke hypotheses alada kore।
4. Evidence Verification Specialist
verification_agent.py		 The Strict Auditor & Fact-Checker Reasoning Agent-er answer check kore। Answer-er moddhe bracketed citation [mitre-T1498.001] asholei retrieved chunk theke ashche kina audit kore। Jodi fake claim ba low evidence pay, tokhon reject kore Coordinator-ke bole: "Evidence kom, abar khojo!" (Feedback Loop)। Jodi corpus-e asholei kono info na thake, tokhon fake answer na diye bole: "Insufficient Evidence, I Abstain"।
Human-in-the-Loop Safety Gate: Shob agent kaj sesh korle Playbook toiri hoy। Kintu system kono din nij theke server shut down ba firewall block korbe na। UI-te ekta mandatory checkbox thakbe: Analyst jokhon check korbe, tokhon-i action execute hobe।

3. Shobgulo Use Case: Ki Input Diben & Ki Output Paben?

Apnar system-e 5-ti prodhan Use Case ache। Niche prottekta use case-er jonno exact ki input likhben, checkbox ki select korben, ebong screen-e ki output ashbe ta deya holo:

Use Case 1: Active DDoS / Network Flood Anomaly Dhora (With Telemetry)

Goal: Live network flow data diye check kora je kono cyber attack hocche kina ebong tar exact confidence score ber kora।

Kothay Diben: Streamlit Dashboard theke "2_Threat_Analysis" page-e jan।

Ki Input Diben (Copy & Paste):
Incident Description:
"Inbound volumetric packet flood on destination port 80 exceeding 85,000 pkts/s with short flow duration (8500 us). Identify threat, map ATT&CK, and advise containment."
Checkbox & Telemetry Inputs:
  • Tick din: [x] Include Structured NetFlow Telemetry
  • Destination Port: 80
  • Flow Packets/s: 85000
  • Flow Duration: 8500
  • Total Fwd Packets: 5000
Click korun: "Run ThreatRAG Analysis"
Screen-e Ki Output Paben (Exact Result):
  1. Threat Classification: Distributed Denial of Service (DDoS)
  2. Calibrated Probability: 99.98% Confidence (Uncertainty: Low • Platt Scaled • ECE = 0.0005)
  3. MITRE ATT&CK Mapping: T1498.001 (Network Denial of Service: Direct Network Flood)
  4. Observable Agent Trace: Expandable cards jekhane Coordinator Plan, Retrieval chunks (similarity 0.82), Reasoning inference, ebong Verification Approved status dekha jabe।
  5. Defensive Containment Playbook:
    • Phase 1 (Immediate Containment): Engage upstream DDoS scrubbing provider (Cloudflare/Akamai) within 15 minutes.
    • Phase 2 (Eradication): Rate-limit SYN packets on border edge router to 10,000 pkts/s per source prefix.
    • Phase 3 (Human Gate): "Authorize Mitigation Execution" checkbox with analyst digital signature.

Use Case 2: Otiter Bikkhato Cyber Attack-er Sathe Tulona (Incident Similarity)

Goal: Bortoman abnormal traffic otite ghote jaowa boro boro incident (e.g. Mirai Dyn DNS, SolarWinds, MOVEit)-er sathe mile kina ta ber kora।

Kothay Diben: "2_Threat_Analysis" ba "4_Similar_Incidents" page-e jan।

Ki Input Diben (Copy & Paste):
Query Text:
"How does an active port 80 SYN flood compare with the 2016 Dyn DNS incident?"
Click korun: "Run Analysis"
Screen-e Ki Output Paben (Exact Result):
  1. Matched Historical Incident: 2016 Dyn DNS Attack (Mirai Botnet) (Similarity Score: 0.84)
  2. Protocol Disambiguation (Senior Analyst Insights):
    • Shared Traits: Both exhibit massive packet volume aimed at edge service saturation.
    • Crucial Difference: The current flow targets web application servers over TCP Port 80 (HTTP), whereas Dyn targeted DNS infrastructure over UDP Port 53 using infected IoT cameras and DVRs.
  3. Lessons Learned: Relying solely on local firewalls fails during multi-gigabit volumetric floods; upstream anycast routing is required.

Use Case 3: Zero-Day Exploit Bujha (MITRE ATT&CK & CISA KEV Grounding)

  3. Analytical Hypotheses: Attacker is attempting web shell deployment (human2.aspx) to exfiltrate Azure blob storage assets.
  4. Citation Audit: 100% precision with exact source link to CISA KEV Advisory date.
